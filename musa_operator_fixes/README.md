# MUSA Operator Fixes

This directory contains only repaired or newly ported operator implementations.
It is separate from the upstream `TileOPs` checkout and the `tilelang-musa` backend.

Organization follows the operator families used by the calibration and TileOPs
reviews.  A repaired operator must be placed in its family and sub-family; its
source provenance, failure class, and validation evidence belong beside it.

No implementation is placed here until its owning failure class is identified.
