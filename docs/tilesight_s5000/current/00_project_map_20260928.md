完成离线验收：40 项测试通过，2 项现场环境测试跳过；模型、编译信息、runtime 分析链路和

## 结果与缓存边界

- `results/`、`delivery/` 中的报告、JSON、manifest、哈希和原始 MCU/MSYS 证据属于结果或交付内容，保留。
- `__pycache__/`、`.pytest_cache/`、`*.pyc`、`*.pyo`、`build/`、`*.egg-info/`、编辑器临时文件均为可重建产物，已清理。
- 新实验应将输出放入 `results/` 的带日期目录；不要把 profiler 默认报告写到仓库根目录。
- 文档只引用正式结果路径；临时日志和中间编译产物不纳入交付包。
